# SW Sliderman user guide

SW Sliderman is a WordPress plugin for responsive layer sliders and hero sections. It is an **early-development preview, not ready for production sites**.

## Functions

- [Create and embed a slider](./getting-started.md) using a shortcode or the **SW SliderMan** block. Only published versions appear to visitors.
- [Edit slides and layers](./editor.md): text, images, buttons, shapes and effects; position them on a visual canvas and save drafts independently of publication.
- [Adapt layouts](./responsive-layout.md) to desktop, tablet and mobile container widths, with inherited properties and per-size overrides.
- [Configure playback and effects](./playback-and-effects.md): arrows, dots, optional autoplay, entrance/exit animation, slide effects and particle fields with static fallback images.
- [Install local fonts](./fonts.md) from the Google Fonts catalog or import static WOFF2 files with licenses. Visitors load the plugin's fonts from the website, not Google.
- [Use templates and transfer sliders](./templates-and-packages.md) using ZIP packages with local media and fonts, or map missing resources on import.
- [Resolve common problems](./troubleshooting.md), including save conflicts, missing resources, background jobs and installation/update issues.

See the [Changelog](./Changelog.md) for documented changes. Developer and release-operation details remain in the [repository documentation](https://github.com/sw-wordpress/sw-sliderman/tree/master/docs).
